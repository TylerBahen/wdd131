Overview

Purpose

My purpose for adding additional functionality to my Plan My Grind app is to facilitate the use of my contact cards for cross-event tracking in my app.

Audience

The intended audience of my app is anyone looking for a CRM-style (for returned missionaries, PMG-like) software to better track goals, events, tasks, and people.

Dynamic elements

I will be adding the functionality of adding contacts to the app, and allowing them to be referenced by things like your calendar, to-do list, and goals. Each contact will have a little tile that you can click on to pull up an expanded view where you can see details, edit them, delete them, etc.

Pseudocode for your project

I'll have an array of objects representing your contacts. Each contact will be ID'd and on app load I'll parse the array into a map for quick reference while preserving insertion order. Then, the other parts of the code can CRUD the contacts map, which I'll also be implementing. I'll also add event listeners to the contact cards to run a function that will pull it up into an expanded view where you can actually use it.
